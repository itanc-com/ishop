# User Story: List Categories

**As a** user or admin
**I want** to view a list of categories, optionally filtered by parent category
**So that** I can browse available product groups

## Acceptance Criteria
- [x] User can request a list of categories
- [x] System returns categories, optionally filtered by parent ID
- [ ] Categories are returned in a structured format

## Notes
- Listing uses a dedicated endpoint and usecase
- Supports hierarchical category structures
