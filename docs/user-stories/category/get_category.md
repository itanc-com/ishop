# User Story: Get Category

**As a** user or admin
**I want** to retrieve details of a category by its ID
**So that** I can view information about a specific category

## Acceptance Criteria
- [x] User can request category details by ID
- [x] System returns category information if it exists
- [ ] Error is returned if category does not exist

## Notes
- Retrieval uses a dedicated endpoint and usecase
- Category details include name, parent, and other metadata
